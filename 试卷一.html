括号嵌套的类型推导基础巩固

运行时间限制：1 秒　运行空间占用限制：64 MB

题目描述

给定一个只包含 char、int、float、double、longlong 以及加法 + 运算符的合法表达式，表达式中允许出现括号 ()。请判断该表达式最终运算结果的数据类型。
规则：括号只改变优先级，不改变类型推导；运算时类型向上转换，结果取两者中“更高”的类型。类型由低到高为：char < int < float < double < longlong。由于只有加法，最终类型就是表达式中出现的最高类型。

输入格式

一行，一个合法表达式（无空格），长度不超过 1000。

输出格式

一行，结果类型的字符串。

动态步长模拟（生命值）基础巩固

运行时间限制：1 秒　运行空间占用限制：64 MB

⚠ 参数 D 为路径长度，直接逐步模拟为 O(D)。若 D 可达 109，需改为只在泉水坐标之间跳跃处理（O(N log N)），否则 O(D) 会超时。当前测试数据 D≤30，未设大规模。

题目描述

小P 从坐标 0 出发，每秒向坐标增大的方向前进 1 个单位，必须到达终点 D。他初始血量为 H，最大血量也为 H。
游戏中有 N 个泉水，第 i 个泉水位于整数坐标 Xi（互不相同，均在 1 到 D 之间），回复量 Vi。
小P 从坐标 0 开始，依次经过坐标 1, 2, …, D：每移动一步（到达下一个坐标）先扣除 1 点血量；若扣除后血量 ≤ 0，则小P 死亡；若到达的坐标恰好有泉水，则立即回复 Vi 点血量（不超过最大血量 H）。
请计算小P 到达终点 D 时的血量；若中途死亡则输出 -1。

输入格式

第一行三个整数 H, D, N。第二行 N 对整数 Xi Vi（保证互不相同）。

输出格式

一行，到达终点时的血量（整数）；若死亡输出 -1。

样例

样例 1
输入
10 5 2
3 4 5 2
输出
10
样例 2
输入
5 10 2
2 3 7 3

区间合并与最大重叠能力提升

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需 O(n log n) 扫描线（用堆维护当前活跃区间的 maxR / minL）。暴力 O(n2) 枚举配对在 n=2×105 时约 4×1010 操作，必超时。数据规模 n≤2×105（测试数据已放大到 2×105）。

题目描述

数轴上有 N 条线段，第 i 条覆盖闭区间 [Li, Ri]。你可以选择任意一个点 P，并将所有包含点 P 的线段合并成一条大线段（这些线段因都含 P，其并集仍是一条连续线段，左端点为其中最小的 L，右端点为其中最大的 R）。
求合并后大线段的最大可能长度。等价地，最大化 (max Ri − min Li)，其中 i 取遍所有覆盖某个公共点 P 的线段。

输入格式

第一行整数 N。接下来 N 行，每行两个整数 Li Ri。

输出格式

一行，最大长度（整数）。

样例

样例 1
输入
3
1 5
2 6
3 4
输出
5

走迷宫的最少步数能力提升

运行时间限制：2 秒　运行空间占用限制：256 MB

BFS 最短路 O(N·M)，每个格子含行/列端点传送（至多 8 条边）。建议 N·M≤106（当前 N,M≤6）。BFS 即最优，勿用重复搜索或全源搜索。

题目描述

给定一个 N×M 的网格，# 表示障碍，. 表示可通行。起点为左上角 (1,1)，终点为右下角 (N,M)，保证这两个格子均可通行。
每次操作消耗 1 点，可以是：
① 向上下左右移动一步到相邻的可通行格子；
② 传送到当前行的两端之一，即 (x,y) → (x,1) 或 (x,y) → (x,M)；
③ 传送到当前列的两端之一，即 (x,y) → (1,y) 或 (x,y) → (N,y)。
求从起点到终点的最少操作次数；若无法到达输出 -1。

输入格式

第一行两个整数 N, M。接下来 N 行，每行 M 个字符（# 或 .）。

输出格式

一行，最少操作次数；无法到达输出 -1。

样例

样例 1
输入
2 2
..
..
输出
2

矩阵路径最大异或和极限挑战

运行时间限制：2 秒　运行空间占用限制：256 MB

数据范围 N,M≤12；用集合 DP 合并异或值，O(N·M·|集合|)。暴力枚举所有路径约 C(N+M-2, N-1)≈7×105（N=M=12）时尚可，但若放大规模须慎重（异或集合可能膨胀）。本题重在“集合 DP 技巧”，规模宜保持较小。

题目描述

给定一个 N×M 的矩阵，每个格子里有一个非负整数（0 ≤ a[i][j] < 231）。从左上角 (1,1) 走到右下角 (N,M)，每次只能向右或向下走一步。路径上所有数字做异或（XOR）运算。
求所有可能路径中异或和的最大值。数据范围：1 ≤ N, M ≤ 12。

输入格式

第一行两个整数 N, M。接下来 N 行，每行 M 个整数。

输出格式

一行，最大异或和（整数）。

样例

输入
1 1
5
输出
5
