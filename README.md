# 计算概论（编程基础）模拟卷 · 三套题

## 本试题为面向北京大学计算概论（A）期中考试命制的模拟题，以24、25年真题为依据，难度略提高，供同学们期中复习参考。
本目录包含三套完整模拟卷，每套 9 题，配套 C++ 测试集与在线判题（runner）。

## 目录结构

```
计算概论模拟卷/
├── 试卷一.html / 试卷二.html / 试卷三.html   # 三套卷的网页（自上而下的 9 个区域）
├── 试卷一测试集/  1/ … 9/                    # 试卷一的测试集（每道题一个文件夹）
├── 试卷二测试集/  1/ … 9/
├── 试卷三测试集/  1/ … 9/
├── runner.py                              # 判题脚本（编译 + 运行 + 比对）
├── gen_exam1.py / gen_exam2.py / gen_exam3.py   # 测试数据生成器（含参考解）
├── gen_html.py                            # 网页生成器
├── 审查报告.md                              # 复杂度与限时审查报告
├── .gitignore                             # git 忽略规则
```

- 每个题目文件夹内：`NN.in`（输入）与 `NN.out`（期望输出），`NN` 从 `01` 起编号。
- 每套卷的**每个题目有 12~17 组测试**（满足“5~20 组”要求）。
- 网页中每题展示的是前两组样例（`01`、`02`）。

## 测试集约定（与网页描述一致，请以网页为准）

部分题目对原始 AI 题干做了“可判题化”的收敛（原题干存在连续量/歧义/超纲算法，无法稳定判题）：

- **试卷一 · 第2题**：原“连续停留回复”改为离散模拟：每移动 1 单位扣 1 血，到泉水坐标立即回血，血量 ≤0 则死亡输出 `-1`。
- **试卷一 · 第3题**：Z 变换改为“之字形填 R 行后按行输出”（每行一个字符串，无多余空格）。
- **试卷一 · 第5题**：传送定义为“可传到当前行/列的两端 `(x,1)/(x,M)/(1,y)/(N,y)`，每次消耗 1”，所有边权为 1，即普通 BFS。
- **试卷一 · 第8题**：数据范围收敛为 `N,M ≤ 12`（异或路径非仿射，更大规模需指数级算法；网页已写明该范围）。
- **试卷三 · 第9题**：采用经典“区间选点”贪心（去掉原题干中含义不清的额外限制条件）。

其余题目与原始题干的考点、输入输出格式保持一致。

## 判题脚本用法

```powershell
# 编译并跑某题的“样例”（网页中展示的前两组），显示完整输入/输出/期望
python runner.py --exam 1 --probs 3 --code 你的代码.cpp --mode sample

# 跑某题的“完整测试集”，逐组显示通过与否及失败详情
python runner.py --exam 1 --probs 3 --code 你的代码.cpp --mode test

# “提交”：跑完整测试集，只输出每题 AC / NOT AC（不暴露数据，不说明原因）
python runner.py --exam 1 --probs 3 --code 你的代码.cpp --mode submit

# 多题：--probs 1,2,3 或 --probs all
python runner.py --exam 2 --probs all --code 你的代码.cpp --mode submit
```

参数：`--exam 1|2|3`（哪套卷），`--probs`（题号/题号列表/all），`--code`（C++ 源文件），`--mode sample|test|submit`。

## 在对话中的提交约定

- 代码后加 **“测试”** → 返回该题样例的逐字符执行结果（输入 / 你的输出 / 期望）。
- 代码后加 **“手动输入 + 具体例子”** → 返回样例执行结果 + 你给出的具体输入的运行结果（含 AC/WA 及错误详情）。
- 代码后加 **“提交”** → 用完整测试集判题，仅返回每题 `AC` 或 `NOT AC`（不展示测试集数据，也不说明 WA/CE/RE 原因）。

## 编译环境

g++ 16.1.0，C++17（`runner.py` 使用 `-std=c++17 -O2 -w`）。超时限制**按题默认 1 秒**，部分数据规模大 / I/O 重的题目放宽到 2 秒（详见 `runner.py` 中 `TIME_LIMITS` 与网页中每题的「运行时间限制」）。
