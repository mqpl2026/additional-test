滑动窗口最大值基础巩固

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需 O(N) 单调队列。暴力 O(N·K) 在 K≈N/2 时约 (N/2)2，N=2×105 时约 1010 操作，必超时。数据范围 N≤2×105（测试数据已放大到 2×105）。

题目描述

给定一个长度为 N 的整数数组和一个大小为 K 的滑动窗口。窗口从最左端移动到最右端，每次向右移动一格。对每个窗口位置，输出窗口内元素的最大值。
数据范围：1 ≤ N ≤ 2×105，要求 O(N) 算法（单调队列）。

输入格式

第一行两个整数 N, K。第二行 N 个整数。

输出格式

一行，N-K+1 个整数，为每个窗口的最大值（空格分隔）。

样例

样例 1
输入
8 3
1 3 -1 -3 5 3 6 7
输出
3 3 5 5 6 7
样例 2
输入
4 2
9 8 7 6
输出
9 8 7

跳跃游戏（最少跳跃次数）基础巩固

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需 O(N) 贪心（维护当前可达边界）。暴力 DP O(N2) 在 N=2×105 时约 4×1010 操作，必超时。数据范围 N≤2×105（测试数据已放大到 2×105）。

题目描述

给定一个非负整数数组，初始位于第 1 个位置。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断能否到达最后一个位置，并输出到达最后一个位置所需的最少跳跃次数；若无法到达输出 -1。
数据范围：1 ≤ N ≤ 2×105。

输入格式

第一行整数 N。第二行 N 个整数。

输出格式

一行，最少跳跃次数；无法到达输出 -1。

样例

样例 1
输入
5
2 3 1 1 4
输出
2
样例 2
输入
5
3 2 1 0 4
输出
-1

字符串回文分割基础巩固

运行时间限制：1 秒　运行空间占用限制：64 MB

题目描述

给定一个字符串 S，将其分割成若干子串，使得每个子串都是回文串。输出所有可能的分割方案，按字典序排列（每行一个方案，同一方案内的子串用 | 分隔）。
数据范围：|S| ≤ 10。

输入格式

一行，字符串 S（仅小写字母）。

输出格式

若干行，每行一个分割方案（子串以 | 连接），按字典序升序。

样例

样例 1
输入
aab
输出
a|a|b
aa|b
样例 2
输入
abc
输出
a|b|c

区间反转与查询能力提升

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需平衡树（Treap / Splay），每次操作 O(log N)。暴力数组翻转 O(N) 单次、总 O(N·M)，在 N=2×105、M=105 时约 2×1010 操作，必超时。数据范围 N,M≤2×105（测试数据已放大）。

题目描述

给定一个 1 到 N 的排列（初始为 1,2,…,N）。进行 M 次操作：
操作 1：1 L R，将区间 [L, R] 内的元素反转；
操作 2：2 X，查询当前位于位置 X 上的值。
每次查询操作输出一行结果。
数据范围：1 ≤ N, M ≤ 2×105，要求使用平衡树（如 Splay / Treap）等 O(log N) 结构。

输入格式

第一行两个整数 N, M。接下来 M 行，每行一个操作（格式见上）。

输出格式

若干行，每次查询操作的结果。

样例

样例 1
输入
5 5
2 3
1 1 5
2 3
1 2 4
2 2
输出
3
3
2
样例 2
输入
3 4
1 1 3
2 1
2 2
2 3
输出
3
2
1

复杂的 DNA 序列编辑距离能力提升

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需 O(|A|·|B|) DP。朴素递归 O(3^(|A|+|B|)) 在长度约 500 时即天文数字超时。数据规模 |A|,|B|≤2000（测试数据已放大，用滚动数组省空间）。

题目描述

给定两个 DNA 序列 A 和 B（由字符 ACGT 组成）。你可以对 A 进行三种操作：插入一个字符、删除一个字符、替换一个字符，每次操作计 1。求将 A 变为 B 的最少操作次数（编辑距离）。

输入格式

第一行字符串 A。第二行字符串 B。

输出格式

一行，最少操作次数（整数）。

样例

样例 1
输入
horse
ros
输出
3
样例 2
输入
intention
execution
输出
5

树的直径极限挑战

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需两次 BFS / DFS，O(N)。对每个点各做一次 BFS 的 O(N2) 做法在 N=2×105 时约 4×1010 操作，必超时。数据范围 N≤2×105（测试数据已放大到 2×105）。

题目描述

给定一棵包含 N 个节点的树，节点编号 1 到 N，每条边有一个非负权值。求树上距离最远的两个节点之间的距离（树的直径）。
数据范围：1 ≤ N ≤ 2×105，边权 ≤ 104。

输入格式

第一行整数 N。接下来 N-1 行，每行三个整数 u, v, w，表示一条连接 u 和 v、权值为 w 的边。

输出格式

一行，最远距离（整数）。

样例

样例 1
输入
2
1 2 5
输出
5
样例 2
输入
3
1 2 1
2 3 2
输出
3

最长递增子序列的方案数极限挑战

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需 O(N2) DP（同时统计方案数）。枚举所有子序列的 O(2N) 做法在 N≥30 即天文数字超时。数据范围 N≤5000（测试数据已放大到 2000）。

题目描述

给定一个长度为 N 的数组，求最长严格递增子序列（LIS）的长度，以及该长度下不同 LIS 的方案数。
数据范围：1 ≤ N ≤ 5000。

输入格式

第一行整数 N。第二行 N 个整数。

输出格式

一行两个整数：LIS 长度 和 方案数。

样例

样例 1
输入
5
1 3 5 4 7
输出
4 2
样例 2
输入
5
5 4 3 2 1
输出
1 5
