题目描述

给定二维平面上的两条线段 AB 和 CD（端点坐标为整数）。判断它们是否相交（包含端点相接、共线重叠等情况）。

输入格式

第一行四个整数 xA yA xB yB。

输出格式

一行，相交输出 YES，否则输出 NO。

样例

样例 1

0 0 2 2
0 2 2 0

YES
样例 2

0 0 1 1

寻找缺失的正整数基础巩固

运行时间限制：1 秒　运行空间占用限制：64 MB

⚠ 复杂度要求：需 O(n) 时间且 O(1) 额外空间（原地循环排序 / 下标哈希）。哈希集合 O(n) 空间不达标，排序 O(n log n) 时间不达标，O(n2) 暴力在 n=2×105 时约 4×1010 操作必超时。数据规模 n≤2×105（测试数据已放大）。

题目描述

给定一个包含 n 个整数的数组（元素可能包含负数、0 和重复值）。请找出其中没有出现过的、最小的正整数。
要求：时间复杂度 O(n)，额外空间复杂度 O(1)（原地哈希，利用数组下标）。

输入格式

第一行整数 n。第二行 n 个整数。

输出格式

一行，缺失的最小正整数。

样例

样例 1
输入
3
1 2 0
输出
3
样例 2
输入
4
3 4 -1 1
输出
2

题目描述

输出格式

a3
输出
aaa

a12b2

aaaaaaaaaaaabb

并查集：连通块查询能力提升

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需并查集，每次操作 O(α)。每次查询暴力泛洪统计岛屿数 O(N·M)、总 O(Q·N·M)，在 N·M≈5×105、Q=3×104 时约 1.5×1010 操作，必超时。数据规模 N·M≤5×105、Q≤3×104（测试数据已放大）。

给定一个 N×M 的网格地图，# 代表陆地，. 代表海洋，上下左右相邻的陆地构成同一个岛屿。初始地图给定后，依次进行 Q 次操作，每次把一个海洋格子变成陆地 #。请在每次操作后，输出当前地图上岛屿的数量。

矩阵旋转与查询能力提升

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需坐标映射公式 O(1) 单次查询；暴力每次真正旋转 O(N2)、总 O(K·N2)，在 N=1000、K=105 时约 1011 操作，必超时。数据规模 N≤1000、K≤105（测试数据已放大）。

题目描述

给定一个 N×N 的矩阵。进行 K 次操作，操作分两种：
1 x y：查询当前矩阵中 (x, y) 位置的值；
2 r：将整个矩阵顺时针旋转 90 度（旋转累计，r 为旋转次数，等价于 r mod 4 次）。
请输出每次查询操作的结果。
提示：不要真的旋转矩阵，应推导坐标映射公式。

输入格式

第一行两个整数 N, K。接下来 N 行，每行 N 个整数。接下来 K 行，每行一个操作。

输出格式

若干行，每次查询操作的结果。

1 1 1
1 3 3
2 1
1 2 2
输出
7

5

1 1 2

1

区间覆盖（选点问题）极限挑战

运行时间限制：2 秒　运行空间占用限制：256 MB

⚠ 复杂度要求：需按右端点升序贪心 O(n log n)；暴力 O(n2) / O(n3) 在 n=2×105 时约 4×1010 操作，必超时。数据规模 n≤2×105（测试数据已放大）。

题目描述

给定数轴上的 N 个闭区间 [Li, Ri]。请你选择尽可能少的点，使得每个区间内至少包含一个选中的点。输出所选点的最少数目。
提示：经典的区间选点贪心——按右端点升序排序，每次在尚未被覆盖的区间中，选其右端点作为一个点。

输入格式

第一行整数 N。接下来 N 行，每行两个整数 Li Ri。

输出格式

一行，所选点的最少数目（整数）。

样例

样例 1
输入
3
1 3
2 4
5 6
输出
2
样例 2
输入
3
1 2
2 3
3 4
输出
2
